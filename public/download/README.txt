Letakkan file APK Monvix di folder ini dengan nama:

    monvix.apk

Nama file harus sama dengan `apk.fileName` di src/config/site.ts dan
APK_FILE_NAME di vite.config.ts. Ukuran file dibaca otomatis saat build,
dan tombol download aktif hanya jika file ada. Setelah APK ditaruh di sini,
jalankan ulang `npm run dev` atau `npm run build`.

Setelah deploy, uji: https://<domain-anda>/download/monvix.apk
